# LangGraph Projects

A collection of small projects, practical tasks, and experiments exploring **AI Agents** and agentic workflows using [LangGraph](https://github.com/langchain-ai/langgraph).

This repository serves as a space to practice, experiment with, and explore different concepts in building AI agents, from basic workflows to more advanced agent architectures.

## Topics Covered

- Building AI Agents with LangGraph
- State Management and Graph Workflows
- Tool Calling and Tool Integration
- Conditional Routing and Decision Making
- Multi-Agent Systems
- Human-in-the-Loop Workflows
- Agent Memory and Persistence

## Repository Structure

Each folder contains an independent project, experiment, or practical task, with its own implementation and documentation.

## Tech Stack

- Python
- LangGraph
- LangChain
- LLMs
- Pydantic

## Purpose

The goal of this repository is to gain hands-on experience with LangGraph and deepen my understanding of agentic AI systems through practical implementation and experimentation.
